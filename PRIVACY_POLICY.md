# Privacy Policy

Effective date: May 28, 2026

Shield Netflix Button Disable is published by VoidArc.

## Data Collection

Shield Netflix Button Disable does not collect, store, sell, or share personal data.

The app does not use analytics, advertising SDKs, tracking SDKs, accounts, servers, or cloud services.

## Accessibility Service

Shield Netflix Button Disable uses the Android Accessibility Service API only to detect and block the NVIDIA Shield remote Netflix button.

The Accessibility Service does not read screen content, inspect app content, record user input, collect personal information, or send data anywhere.

## Data Sharing

No user data is shared with third parties.

## Data Retention and Deletion

Because the app does not collect or store user data, there is no user data to retain or delete.

## Security

The app runs locally on the user's Android TV device. No user data is transmitted from the device.
